# `@ktav-lang/js-linux-arm64-gnu` platform binaries

This package contains the prebuilt N-API and C ABI libraries for
`aarch64-unknown-linux-gnu`. It is an optional dependency of [`@ktav-lang/ktav`](https://www.npmjs.com/package/@ktav-lang/ktav)
and is normally installed automatically; install the main package to
use the JavaScript API.
