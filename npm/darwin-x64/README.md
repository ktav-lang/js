# `@ktav-lang/js-darwin-x64` platform binaries

This package contains the prebuilt N-API and C ABI libraries for
`x86_64-apple-darwin`. It is an optional dependency of [`@ktav-lang/ktav`](https://www.npmjs.com/package/@ktav-lang/ktav)
and is normally installed automatically; install the main package to
use the JavaScript API.
