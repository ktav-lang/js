# `@ktav-lang/js-win32-x64-msvc` platform binaries

This package contains the prebuilt N-API and C ABI libraries for
`x86_64-pc-windows-msvc`. It is an optional dependency of [`@ktav-lang/ktav`](https://www.npmjs.com/package/@ktav-lang/ktav)
and is normally installed automatically; install the main package to
use the JavaScript API.
